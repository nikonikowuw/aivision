   - 未录人脸时，原“人脸管理”文本变为“**补录人脸**”，主色加粗提示。

### 原型 2：新增人员「一步到位」弹窗 (AddPersonModal)

```text
+----------------------------------------------------------------------------+
| 新增人员档案                                                             [X] |
+----------------------------------------------------------------------------+
|                                                                            |
|  +---------------------------+   人员标识 (Person ID) *                    |
|  |                           |   [ 请输入人员工号/唯一标识，留空自动生成  ] |
|  |     [ + 点击/拖拽图片 ]   |                                             |
|  |                           |   人员姓名 (Name) *                         |
|  |   支持 JPG/PNG/WebP 格式  |   [ 请输入人员真实姓名                   ] |
|  |   建议正面免冠、光照均匀  |                                             |
|  |                           |   建库说明                                  |
|  |   (可选，上传即自动建库)  |   ℹ 支持录入基本信息时同步注册首张主特征图。  |
|  +---------------------------+     也可先建档，后续在人脸抽屉中批量补录。  |
|                                                                            |
+----------------------------------------------------------------------------+
|                                                      [ 取 消 ]  [ 确 定 ]  |
+----------------------------------------------------------------------------+
```

**交互流与容错设计**：
1. **即时预览**：用户拖拽或点击选择照片后，左侧上传框立即转为本地图片预览，右上角带 `[ X ]` 清除按钮；
2. **串联提交流程**：
   - 用户点击「确定」时先通过表单校验；
   - 第一步：调用 `createPersonApi({ name, personId })` 创建人员实体；
   - 第二步：若用户选了首图，紧接着调用 `registerPersonFaceApi(personId, imageFile)`；
   - 容错提示：若人员创建成功但图片注册失败（如图片中未检测到人脸），弹出 Warning 提示：“人员创建成功，但人脸未检测到有效特征，请稍后在人脸抽屉中重新上传”，同时刷新表格并关闭弹窗，不造成数据孤岛。

**设计要点**：
1. **空间重构**：
   - 抽屉宽度 780px，内容区由过去的单列改为 **2 列响应式 Grid**，每张样本卡片约 350px 宽；
   - 一屏可容纳 4~6 张样本，大幅减少滚动深度。
2. **主特征图高亮与自动置顶排序机制（Primary-First Ordering）**：
   - **永久置顶**：主特征图在相片墙中永远自动排在第 1 位（#1 首选主图），佩戴醒目的 Primary 主色边框与金标 `👑 算法主特征图`；
   - **交互平滑置顶**：当用户在任意卡片点击「设为主图」时，该样本通过平滑位移动画即刻重排飞升至第 1 位，原主图顺延为辅助样本，用户心智模型高度统一；
   - 非主图卡片在左上角提供显式单选按钮 `[ ○ 设为主图并置顶 ]`。
3. **原位对比与灯箱，移除多余 Modal**：
   - 卡片内提供 `(•) 112×112特征图 / ( ) 原图` 单选切换；
   - 点击放大镜或图片直接激活 Ant Design `<Image.PreviewGroup>` 全屏灯箱，支持前后切换所有样本原图，支持滚轮放大缩小，彻底剔除二级 Modal 弹窗。
4. **批量上传**：
   - 拖拽区支持 `multiple: true`；一次选多张时前端进行数量校验（`selected.length + current.length <= 10`），自动队列式依次注册并实时刷新。

## 4. 交互状态与异常容错规范

1. **配额超限保护**：当人员样本已有 10 张时，抽屉上传区自动切换为 Alert 禁用提示，无法继续上传。
2. **多图上传数量截断**：若剩余可传配额为 2 张，而用户拖入了 4 张，前端即刻拦截并提示“当前仅可再上传 2 张样本，已超出上限”，避免无效请求。
3. **未录入底库视觉醒目**：表格头像为警示虚线框，用户点击即可直接唤起该人员的人脸抽屉进行补录，交互链路最短。
4. **全屏灯箱原生无缝**：Ant Design `<Image.PreviewGroup>` 内部接管键盘 ESC、左右翻页、缩放与旋转，无需手写复杂图片查看器。
