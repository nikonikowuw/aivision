# 摄像头管理页面 Bento 卡片重构与 UI 现代化 PRD

## Goal

将传统基于笨重后台表格的摄像头管理页面，全面重构为专为边缘 AI 视频网关（4~32 路视频通道）量身定制的**现代边缘设备 Bento 卡片矩阵 (Edge Camera Bento Matrix)**。

对标 Linear / Vercel Edge / Verkada 的工业科技克制美学，彻底摒弃传统 ERP 密集表格，聚焦**设备资产接入、握手测活、流媒体元数据感知、按需轻量视频抽检与全生命周期控制**，实现零视频流性能常驻损耗、数据纯粹、高质感的科技交互体验。

---

## 核心设计决策 (Grilling Decisions)

1. **纯 Bento 矩阵骨架**：
   - 彻底摒弃传统大表格，采用全响应式工业硬件设备 Bento 矩阵 + 顶部边缘视频网关资产看板。
2. **纯数据工业资产卡片，零冗余常驻流开销**：
   - 本页面定位为**网络资产与接入管理**，而非监控大屏（/live）或算法工作台（/resource/task）；
   - 卡片日常不常驻拉取实时视频流，避免边缘网关硬件解码器过载与浏览器卡顿；
   - 聚焦连接健康态、芯片等宽编号、音视频编码规格、握手往返延迟微条、RTSP 码流脱敏展示与就地快捷测活。
3. **按需轻量级快速预览（Spot-Check HUD Modal）**：
   - 卡片提供「👁 快速预览」入口，点击弹出微型工业 HUD 视窗，就地加载实时流以快速核验机位画面与连通性；
   - 支持主/子码流切换，展示实时分辨率与 FPS；
   - **算力自释放机制**：视窗关闭时立即调用 `stopLivePreviewApi` 并销毁播放器，释放边缘拉流与解码算力；
   - 编辑/接入弹窗内在测活成功后亦支持一键查看实时画面验证。
4. **顶部边缘资产看板 (Edge Camera Hub)**：
   - **全局连通健康度**：展示 `在线路数 / 总接入数`（带翡翠绿微光脉冲与连通率百分比），醒目标注异常数，**点击异常数字直接一键过滤出所有故障摄像头**；
   - **传输与规格分布**：主编码（H.265/H.264 占比）、传输策略（TCP 占比）与双码流覆盖率；
   - **局域网握手延迟基准**：平均探测耗时毫秒级指示条；
   - **敏捷工具栏**：实时模糊搜索（名称/编号/IP）、状态过滤胶囊群、`[ ⚡ 全局一键巡检 ]`（原地测活全部设备）、`[ ＋ 接入摄像头 ]` 主按钮。
5. **安防厂商快捷预设与结构化握手诊断面板 (Onboarding & Diagnostics)**：
   - 弹窗内置主流厂商预设胶囊：`自定义 / 海康威视 (Hikvision) / 大华 (Dahua) / 宇视 (Uniview) / TP-LINK`，自动套用主/子码流规则，用户仅需填 IP、端口与密码；
   - 弹窗内嵌高科技质感握手诊断面板：毫秒级响应条、TCP/UDP 协商过程、自动提取编码/分辨率/帧率、失败时精准排障代码与指引。
6. **悬浮玻璃拟态操作坞 (Floating Glass Action Dock) 与空状态**：
   - 卡片日常不常驻多选框，Hover 或选中时唤出圆环 Checkbox；
   - 勾选设备后，底部中央升起磨砂玻璃悬浮胶囊：展示选中数量，提供 `[ ⚡ 批量测活 ]`、`[ 🗑 批量删除 ]`、`[ ✕ 取消全选 ]`；
   - 0 设备时展示雷达探测微光工业引导卡片。

## Acceptance Criteria

- [ ] 顶部资产看板实时统计总数、在线数、异常数、平均延迟、编码分布，支持点击异常设备一键过滤。
- [ ] 状态过滤胶囊与搜索框无缝联动。
- [ ] Bento 设备卡片呈现：摄像头名称、`cam-id`、连接呼吸灯、规格微矩阵、脱敏 RTSP 路径、最近测活时间与单机极速测活。
- [ ] 卡片支持「快速预览」弹窗抽检画面，支持主/子码流切换，关闭时自动释放流。
- [ ] 卡片支持多选，底部弹出磨砂玻璃操作坞，支持批量测活与批量删除。
- [ ] 新建/编辑弹窗提供主流安防厂商预设模板与结构化网络握手诊断面板，支持直接预览验证。
- [ ] 严格对齐 dark / light 双色工业科技主题，CSS glow pulse 动效与过渡平滑。
- [ ] 国际化多语言支持完整（zh-CN, en-US, zh-TW），无硬编码文本。
