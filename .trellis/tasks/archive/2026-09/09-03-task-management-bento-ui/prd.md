# 任务管理页面 Bento 卡片重构与 UI 现代化 PRD

## Goal

将现有基于密集传统后台表格的视频分析任务管理页，全面重构为专为边缘 AI 视频网关（4~64 路视频通道）量身定制的**现代边缘 Bento 卡片矩阵 (Edge Bento Matrix)**。

对标 Linear / Vercel Edge / Verkada 的工业科技克制美学，彻底摒弃传统 ERP 臃肿边框和密集表格，实现极致轻量、零冗余流开销、数据纯粹的高级感与敏捷交互体验。

---

## Background & Pain Points

1. **边缘场景与数据体量错配**：
   - 传统后台表格适用于成千上万条记录的云端检索，而边缘计算设备（如 RK3588、Ascend 310B、工控机等）受硬件编解码与 NPU 算力上限约束，通道数通常在 4~32 路（极少超 64 路）。
   - 传统列表在几十路规模下显得笨重、呆板，无法直观体现每个物理视频通道的 AI 挂载态与设备实时生命力。
2. **避免冗余拉流带来的算力雪崩**：
   - 在任务管理页面如果批量拉流播放，会严重挤占边缘盒子宝贵的硬件解码资源和网络带宽。
   - 必须贯彻“概览页纯数据指标、工作台按需拉单流”的职责分离原则。
3. **视觉噪音与框中框（Box-in-Box）**：
   - 旧有展开行存在大量冗余文本标签（如“实时吞吐:”、“算力占用:”）和嵌套容器，需要进行现代科技视觉降噪（Data-First, Typography & Micro-meters）。

## Requirements

### 1. 顶部全局设备看板 (Top Edge KPI Dashboard)
- **左侧：三维一体微型 Bento KPI 指标卡**：
  - **通道运行状态**：展示 `在线路数 / 总任务数`（如 `8 / 8 在线`），搭配高亮绿色呼吸光晕与百分比；
  - **调度算法集群**：展示活跃模型实例总数（如 `19 个活跃实例`），副标展示模型健康度；
  - **NPU 算力负荷与余量**：展示 `已用 / 总配额 Units (占用率%)`，内嵌动态变色（绿/琥珀/红）发丝级能量条。
- **右侧：紧凑工具栏**：
  - 实时模糊搜索框（支持任务名称、摄像头 ID、挂载算法名过滤）；
  - 状态快捷过滤胶囊（`全部` / `运行中` / `已停止` / `未配置算法`）；
  - 高光聚焦的 `[＋ 新建分析任务]` 按钮。

### 2. 核心 Bento 任务卡片解构 (Card Anatomy)
页面主体采用响应式自适应网格（1列 / 2列 / 3列）：
- **卡片头部 (Header)**：
  - 摄像头专属 SVG 标识 + 任务名称；
  - `cameraId` 等宽字体徽标（如 `cam-01`）；
  - 通道全局运行状态标签（运行中 / 启动中 / 降级 / 停止 / 异常），带微呼吸动效指示灯；
  - 通道主期望启停 Switch 开关（一键切断/启动该通道整体解码与推理调度）；
  - 更多操作下拉菜单（···）：编辑任务名称、删除任务。
- **卡片微型指标三连 (KPI Trio)**：
  - 实时吞吐：高对比等宽数字 `14.8` + 单位 `fps`；
  - 算法密度：`2` + 单位 `个模型`；
  - 算力占用：`16` + 单位 `Units`。
- **模块化 AI 流水线插槽 (AI Pipeline Dock)**：
  - 摒弃嵌套边框，采用单行精炼微胶囊（Sleek Row Capsule）；
  - 展示算法名称、版本/规则徽标（如 `2 规则设定` 或 `全屏巡检`）；
  - 超细微型动态吞吐能量条（`14.8 / 15.0 fps`），吃满帧率呈翠绿，丢帧降级呈琥珀；
  - 单算法独立的使能 Switch 开关，以及快捷配置 `[⚙]` 按钮（就地打开参数编辑）；
  - 底部虚线引导槽位 `[＋ 挂载算法模型]`；若未配置任何算法，呈现空状态槽位引导。
- **卡片底部 (Footer)**：
  - 毫秒级心跳与最后上报帧相对时间（如 `0.3s 前`）；
  - `[ 进入算法工作台 ↗ ]` 操作按钮，点击滑出完整的 `InstanceDrawer`（按需播放单路视频流并进行多边形 ROI 规则绘制）。

### 3. 视觉化算法模型集市：左右分栏与动态模型专属参数 (Split Marketplace & Dynamic Schema)
- **彻底告别传统下拉框与两步割裂流**：
  - 传统 `<select>` 下拉框交互单调、缺乏信息承载力，全面升级为**左右分栏 AI 算法模型集市弹窗 (Split Model Marketplace Modal)**；
  - 顶部导航清晰展示目标通道名称、NPU 算力余量（如 `⚡ NPU 算力余量: 22 / 64 Units 充足`）；
  - **左栏（约 42%）：算法模型货架 (Model Shelf)**：
    - 顶部支持按门类胶囊快捷筛选（`全部` / `通用检测` / `人脸感知` / `安全消防` / `交通卡口`）；
    - 垂直单列卡片列表，容纳海量算法无拥挤：呈现模型渐变微图标、名称、版本、算力徽标（`⚡ 8 Units`）、描述与硬件推理延迟基准（`~8.2ms`、`NPU就绪`）；
    - 点击卡片瞬间高亮选中（翡翠绿光晕），右侧调参面板无缝即时切换；
  - **右栏（约 58%）：模型专属动态参数配置台 (Dynamic Schema Inspector)**：
    - **通用调度基准**：采样 FPS 滑块与 `5/10/15/25` 快捷档位、MotionGate™ 像素节能门控、初始调度使能；
    - **模型专属异构参数（根据选中的算法模型动态渲染对应表单）**：
      - **YOLO 目标检测 (yolo26n)**：目标置信度阈值滑块、IoU 非极大值抑制滑块、关心目标类别使能（人员 / 车辆 / 非机动车 / 箱体包裹）；
      - **FaceNet 人脸识别 (face_detect)**：人脸比对相似度阈值（0.5~0.95）、最小检测像素尺寸（32~128px）、大角度/模糊侧脸过滤开关、红外活体防伪核验开关；
      - **FireSmoke 烟火告警 (fire_smoke)**：明火识别灵敏度（0.5~0.98）、半透明烟雾羽流扩散追踪开关、夜间低照度自适应对比度增强开关；
      - **PlateOCR 车牌识别 (plate_ocr)**：字符光学识别置信度、支持车牌类别（蓝牌燃油 / 绿牌新能源 / 黄牌货客车）、大倾角透视四边形自动校准；
      - **SafetyHelmet 安全帽合规 (helmet_detect)**：安全帽穿戴置信度、人体头肩骨架严格关联防手持误报开关、同步核查反光警示背心开关；
    - **硬件算力预检实时对账条**：显示本次申请算力（`+8 Units`）及调度后总负荷，确保不超限；
    - **即时配置一步到位**：点击 `[ 确认挂载并立即调度 ]` 即可将完整参数直接注入后台流水线，彻底告别挂载后再去找二次调参入口的繁琐操作。
- **摄像头接入源可视化选择 (Camera Source Picker)**：
  - 新建任务时采用视频流卡片列表取代下拉框，展示摄像头名称、`cam-id`、流协议（RTSP）与分辨率规格，提供清晰直观的接入体验。

### 4. 深度工作台：三栏经典 IDE 架构 (Three-Column Studio Layout)
- **彻底解决多算法容纳与视听调参割裂痛点**：
  - 彻底摈弃在顶部横排胶囊导致“算法多了挤不下/溢出截断”的缺陷，全面升级为工业级 **三栏经典 IDE 工作台架构 (Three-Column Studio)**；
  - **顶部导航栏极简纯粹**：
    - 常驻任务名称、`cam-id`、1080P@25fps 规格与全局算力调度概要（如 `● 已挂载 2 个算法 · 16 Units · 调度就绪`），绝不在顶部横塞容易挤爆的胶囊标签；
  - **左栏（约 25%）：算法流水线资产树 (Vertical Instances Pipeline)**：
    - **垂直纵向排列，无限容纳**：无论配置 1 个、5 个还是 10 个算法，纵向无限自适应延伸，支持平滑滚动；
    - 每个算法卡片独立呈现：健康呼吸灯、算法全称、当前实时与目标 FPS 微吞吐能量条（`14.8 / 15.0 fps`）、规则数徽标（`2 规则`）、独立启停 Switch、以及算力标记（`⚡ 8 Units`）；
    - 点击任意卡片触发翡翠绿高光选中，中栏画布与右栏调参面板瞬间同步联动；
    - 底部固定常驻 `[ ＋ 挂载新算法模型 ]` 按钮；
  - **中栏（约 42%）：实时视频流与几何规则标注画布 (Video & Geometry Canvas)**：
    - 纯净 16:9 WebRTC 实时流暗色大视窗，专供渲染当前选中算法的实时检测框（置信度、追踪 ID、推理延迟）；
    - 动态叠加当前算法的多边形防区（ROI）与越界警戒线；
    - 底部悬浮快捷绘图工具（绘制多边形、绘制警戒线、抓取快照）与视频流硬件解码状态条；
  - **右栏（约 33%）：即时属性检查器 (In-place Parameter Inspector)**：
    - **零弹窗直调**：专供当前选中算法就地调参：
      - 采样帧率滑块与预设档位（`5 / 10 / 15 / 25 fps`）；
      - 置信度阈值 (Confidence) 与 IoU 抑制阈值；
      - 目标类别使能过滤（人员、车辆、非机动车、包裹）；
      - MotionGate™ 像素节能门控；
      - 当前算法绑定的几何防区规则列表与添加入口；
    - **所见即所得**：右侧改动参数，中栏画布与 NPU 负载实时联动，底部提供 `[ 保存并生效 ]`。

### 5. 批量操作与悬浮玻璃拟态操作坞 (Floating Glass Action Dock)
- **卡片多选**：卡片平时不常驻死板复选框；鼠标悬停在卡片左上角或处于选中态时，优雅显现半透明圆环勾选框；
- **悬浮操作坞**：一旦有卡片被勾选，页面底部中央平滑升起深色磨砂玻璃（`backdrop-blur`）悬浮胶囊：
  - 显示当前已选中路数（如 `✦ 已选中 3 路任务`）；
  - 提供批量快捷操作：`[ ▶ 批量启动 ]`、`[ ⏸ 批量停止 ]`、`[ 🗑 批量删除 ]`（带二次确认）、`[ ✕ 取消选择 ]`。

### 6. 实时监控、动效质感与防抖保护 (Real-time & Motion)
- **就地防抖轮询**：每 2 秒静默轮询后端状态，严格保持卡片 DOM 顺序（按 `cameraId` 锁定），禁止轮询时重排导致卡片跳位；
- **平滑过渡**：数值与进度条使用 `transition-all duration-500 ease-out` 平滑过渡；
- **呼吸灯动效**：活跃任务与健康算法实例状态点带有轻微的 CSS Glow Pulse 呼吸光效；
- **卡片悬停触感**：Hover 时轻微上浮（`-translate-y-0.5`），附带主色 subtle 边框光晕。

### 7. 主题双适配与空状态引导
- **暗色模式（Dark Mode，首推边缘科技感）**：深邃 Slate/Zinc 色系、高对比等宽数字、半透明磨砂质感；
- **浅色模式（Light Mode）**：冷白纯净高对比度、无油腻投影；
- **设备未配置引导（Empty State）**：0 任务时，展示边缘硬件专属引导卡片，一键唤醒「从可用摄像头创建首条分析流水线」。

## Technical Dependencies & Non-Functional Requirements

1. **接口完全兼容**：
   - 沿用并兼容现有的 API：`getTaskListApi`、`getTaskStatsApi`、`setTaskEnabledApi`、`setInstanceEnabledApi`、`deleteTaskApi`、`batchDeleteTasksApi`、`createTaskApi`、`updateTaskApi`。
2. **现有组件联动**：
   - `TaskFormModal.vue`（任务创建与编辑弹窗）；
   - `InstanceDrawer.vue`（单任务深度工作台：WebRTC/HLS 播放、几何规则多边形绘制）；
   - `InstanceFormModal.vue`（单算法参数配置弹窗）。
3. **零视频流性能保障**：
   - 任务列表网格内绝不实例化任何视频播放器（WebRTC / HLS / FLV），保证低端工控机与前端浏览器 0 额外编解码负载。
4. **权限对齐**：
   - 保留现有的 RBAC 权限指令控制（`v-access:code="['resource:task:add']"`、`['resource:task:edit']"`、`['resource:task:delete']"`）。

## Acceptance Criteria

- [ ] 顶部概览展示通道健康数、活跃算法数与 NPU 算力负荷变色能量条。
- [ ] 页面主体呈现响应式 Bento 卡片矩阵，彻底替代旧版死板表格。
- [ ] 卡片内部清晰呈现 1:N 结构：包含通道主控、KPI 三连、算法流水线微胶囊槽位与底部工作台入口。
- [ ] 单个算法槽位支持独立启停、状态呼吸灯、实时/目标 FPS 微进度条与配置入口。
- [ ] 深度工作台采用三栏经典 IDE 架构（左栏垂直算法树 + 中栏视频几何画布 + 右栏属性检查器），无论算法数量多少均纵向无限容纳，且右侧检查器支持按算法类型动态呈现专属推理参数。
- [ ] 挂载算法与选择视频源彻底摒弃传统下拉框，采用现代左右分栏算法集市（左侧门类与模型货架 + 右侧模型专属动态参数）。
- [ ] 动态参数表单针对不同算法模型（YOLO、FaceNet、FireSmoke、PlateOCR、SafetyHelmet 等）渲染完全异构的定制控制组件（置信度、人脸尺寸、烟火灵敏度、车牌分类等）。
- [ ] 挂载新算法时提供全参数即时配置套件（FPS、模型专属阈值、类别过滤、节能门控），一步到位直接投入调度，杜绝挂载后再二次找入口。
- [ ] 勾选卡片时平滑唤出底部磨砂悬浮操作坞，支持批量启停与批量删除。
- [ ] 轮询更新时数据就地平滑过渡，卡片位置严格锁定不跳位。
- [ ] 完美兼容暗色与浅色模式，保持 Linear 级边缘工业科技质感。
- [ ] 前端打包检查（`pnpm check`）与单元测试均通过，无类型与样式报错。

## Out of Scope

- 后端 API 与 GORM 模型改造（纯前端 UI 交互与视觉架构升级）。
- 多边形规则编辑器（`DetectionRuleEditor.vue`）底层几何算法改动（沿用现有已验证逻辑）。
